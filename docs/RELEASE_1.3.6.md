# Kiosk 1.3.6 — 현금 취소와 관리자 복구

## 변경 내용

- 현금 결제 준비 중 바로 취소할 때 초기화와 취소 명령이 겹치던 문제를 수정했습니다. 현금 미투입 취소 시 불필요한 잠금이 발생하던 경로를 보완했습니다.
- 결제 잠금 화면에 **관리자 복구**를 추가했습니다. 기존 관리자 비밀번호로 인증하고 실제 처리 결과를 확인한 뒤 **기록 보관 후 처음으로**를 선택할 수 있습니다.
- 원본과 화면의 거래 정보를 암호화해 보관하며 등록·숙소/동·장비 설정은 유지합니다. 현금 관련 건은 투입구 정지 응답을 확인하고, 보관 실패나 거래 변경 시 잠금을 유지합니다.
- 미확정 거래 보호와 거래 중 업데이트 보류는 유지합니다. 복구 버튼은 카드 승인·취소, 현금 반환, 예약 생성·취소를 실행하지 않습니다.

## 설치 파일

- [Windows 64비트 (x64)](https://github.com/worldchamps/kiosk-private-releases/releases/tag/v1.3.6)
- [Windows 32비트 (ia32)](https://github.com/worldchamps/kiosk-private-releases/releases/tag/v1.3.6-ia32)

해당 릴리스의 `installer.exe`를 사용합니다. 비공개 저장소 접근 권한이 있는 GitHub 로그인이 필요합니다.
CPU가 64비트여도 설치된 Windows가 32비트이면 32비트 파일을 선택합니다.

기존 PC는 같은 Windows 사용자·같은 설치 위치·같은 비트수로 업데이트합니다.
프로그램 제거, 재등록 또는 사용자 데이터 삭제는 하지 않습니다. 예상치 못한 등록창이 나오면 중단하고 확인합니다.
잠긴 기존 1.3.5에는 관리자 복구 버튼이 없습니다. 이 경우 운영자가 실제 거래와 장비 정지를 확인한 뒤 새 설치본을 적용해야 합니다.
업데이트만으로 미확정 거래가 삭제되거나 잠금이 풀리지는 않습니다.

## 검증 및 한계

- 소스 자동 검사 267개, 타입 검사, 프로덕션 빌드 통과.
- 가상 거래로 비밀번호 오류, 현금 0원·카드·손상 기록 복구, 보관 실패 시 잠금 유지, 첫 화면 복귀를 확인했습니다.
- Windows safeStorage의 암호화 보관과 재시도, 원본·기존 설정 보존을 격리된 가상 기록으로 확인했습니다.
- 실물 장비의 정지 응답·카드 승인·현금 반환·인쇄 및 현장 설치·재부팅 검증을 대체하지 않습니다.
- 토스 프론트 플러그인은 변경·배포하지 않았으며, 현장의 토스 연결 장애 자체가 해결된 릴리스는 아닙니다.
- 기존 런타임과 의존성을 유지합니다. 의존성 검사에서 런타임 기준 31개(개발 도구 포함 48개)의 경고가 남아 있으며, 이를 해소한 보안 릴리스는 아닙니다.

릴리스 게시는 장비 업데이트 명령을 생성하지 않습니다. 개별 장비 반영은 별도 지정·승인이 필요합니다.
