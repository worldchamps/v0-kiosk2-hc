# 키오스크 AI 도우미

예약 조회, 체크인, 결제, 키 수령 화면에서 한 번에 한 행동씩 안내합니다. 거래나 키 발급은 직접 실행하지 않습니다. 사용자가 “음성 대화 시작”을 누르면 음성 전송 안내 후 마이크를 켜며, 부분 자막을 바로 표시합니다. 잠시 말이 없으면 현재 발화를 OpenAI STT로 확정하고, Gemini가 허용된 안내 주제를 선택한 뒤 화면 안내를 글과 음성으로 제공합니다.

## 모델과 개인정보

- STT: OpenAI `gpt-live-transcribe` transcription session. API 키는 서버에만 두고, 브라우저에 전달하는 값은 짧게 유효한 세션 토큰입니다.
- 안내 판단: Gemini `gemini-3.5-flash-lite`. 서버는 키워드로 제한한 주제 후보만 Gemini에 보내며, 원문 질문·이름·예약 정보는 전송하지 않습니다. 답변은 저장된 고정 안내에서 생성합니다.
- TTS: Gemini `gemini-3.8-flash-lite-tts`. 한국어, 빠르지만 차분하고 친절한 젊은 여성 호텔 안내 스타일을 지시합니다. 실제 음성의 나이를 보장하지 않습니다.
- Preview에서는 객실 가용성 조회를 하지 않습니다. 현장 설치 전 Preview에서 흐름과 안전 안내를 확인합니다.

`OPENAI_API_KEY`는 음성 대화에, `GEMINI_API_KEY`는 안내 판단 및 음성 생성에 필요합니다. 키를 브라우저나 저장소에 넣지 않습니다. 현재 음성 전송은 사용자 동의에 따라 OpenAI로 전달됩니다. 개인정보(성명, 전화번호, 예약번호, 카드·계좌번호 등)는 말하지 말라는 안내를 시작 전에 표시합니다.

마이크 입력은 브라우저에서 음성 구간과 침묵을 감지해 발화가 끝났을 때 전송을 확정합니다. 서버의 침묵 길이 기본값은 700ms이며 환경값으로 400–1800ms 범위에서 조정할 수 있습니다. 질문 직후 침묵이 지속되면 답변을 만들고, 사용자가 답변 중 말하면 재생을 멈추고 새 발화를 받습니다. 세션은 최대 3분이며 종료 시 마이크와 연결을 정리합니다.

결제 승인, 체크인 완료, 키 발급 여부를 확인할 수 없거나 화면 상태가 안내와 다르면 다음 조작을 권하지 않고 직원 연락으로 전환합니다. 반복해서 이해하지 못한 경우에도 직원을 안내합니다. 속도 목표는 현장 기기 기준 측정 후 정합니다.

## 확인

`npm.cmd run typecheck`, `npm.cmd run test:qa`, `npm.cmd run build`를 실행합니다. 자동 검사는 모델 계정 연결, 실제 마이크 권한과 현장 사용성을 증명하지 않습니다. 현장 시험은 별도 운영 승인과 안전한 테스트 결제 수단이 준비된 뒤 진행합니다.

## 디지털 취약 사용자 현장 시험

운영 장비 설치는 별도 승인 전까지 하지 않습니다. 현장 시험은 운영자가 시험 날짜, 대상 장비, 안전한 테스트 예약·결제 수단, 개인정보 비공개 기록 방식을 승인한 뒤 진행합니다. Preview 검사는 현장 결과를 대신하지 않습니다.

1. 대표 디지털 취약 사용자 5명을 모집하고 직원이 가까이 대기하되 먼저 조작을 대신하지 않습니다.
2. 사용자는 안내를 들으며 예약 조회, 체크인, 결제 화면 통과, 키 수령 안내 확인을 진행합니다.
3. 거래 실행, 개인정보 노출, 상태가 불분명한데 다음 조작을 안내하는 위험 사례를 관찰합니다.
4. 두 차례 재시도 뒤에도 진행하지 못하거나 위험한 오안내 가능성이 있으면 직원 연락으로 전환하고 시험을 중단합니다.
5. 5명 중 4명 이상이 직원 조작 없이 독립 완료하고 위험한 오안내가 0건이어야 통과입니다.
