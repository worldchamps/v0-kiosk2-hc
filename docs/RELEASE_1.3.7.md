# Kiosk 1.3.7 준비

## 변경

- 잔돈·현금 반환 오류는 관리자 코드 없이 기록을 보관하고 첫 화면으로 자동 복귀한다.
  숙박대금 전액을 받았어도 입실과 예약 생성을 중단한다. 보관 또는 투입구 정지 실패 시에는 기록을 보존하고 재시도한다.
- 최소 현금 오류 기록을 PMS로 전송한다. 오프라인이면 로컬 암호화 파일에서 재시도하며 동일 건을 중복 생성하지 않는다.
- 토스 프론트 LAN 인증 응답 지연, 단절된 연결이 열린 채 남는 경우의 재연결을 보완하고 실제 주소·인증 상태·오류를 표시한다.
- 기존 카드 승인 복구, 예약 증빙, 동별 제한, 등록 정보 및 장비 설정을 유지한다.

상세: [현금 오류 복구](PAYMENT_RECOVERY.md), [토스 LAN 연결](TOSS_FRONT_LAN_RECOVERY.md).

## 개발 PC 검증

- 전체 JavaScript/TypeScript 회귀 테스트 279개, 타입 검사와 Next.js 프로덕션 빌드 통과.
- 토스 WebSocket 가상 단말기 승인·취소·QR·응답 유실 복구 통합 검사 통과.
- 실제 Windows Electron 28.3.3 safeStorage에서 코드 없는 암호화 보관·중복 재시도·다른 설정 보존 확인.
- 운영 API 쓰기와 실장비 접근을 막은 브라우저에서 현금 오류 자동 복귀와 보관 실패 시 원본 유지 확인.
- PMS 전체 테스트 164개 및 빌드, 가상 오류 기록 화면 확인.
- x64/ia32 모두 Python 장비 계약 17개와 설치파일 빌드·패키지 검증 통과.
  각 비트수의 내장 Python self-test, Node/native 모듈 및 프로덕션 웹 서버를 실제 실행했다.
  검사 중 클라우드 및 실장비에는 연결하지 않았다.

기존 의존성의 audit 취약점은 해결되지 않았다. 2026-09-14 조회 기준 운영 의존성 31건(critical 4),
전체 의존성 48건(critical 6)이며 이번 패치에서 의존성 버전은 변경하지 않았다.

## 배포 상태

1.3.6을 덮어쓰지 않는다. 1.3.7 x64/ia32 설치파일의 빌드·패키지 검증을 완료했다.
GitHub 게시, 전용 업데이트 DB 등록, PMS 운영 배포, 지정한 단일 현장 장비의 업데이트 및 실제 토스 연결 검증은 별도 단계다.
개발 PC 검사 통과를 실제 현장 장애 해결이나 카드 결제 성공으로 간주하지 않는다.
