# Kiosk 1.3.8 현금 통신 점검

- 결제 완료/취소 단계의 초기화와 투입 중지 실패 사유를 구분한다.
- 설치형에서도 ONEPLUS 송수신, 앱 전달, 명령 결과와 시간을 로컬 파일에 보관한다.
- 관리자 인증 후 무현금 초기화/투입 중지 점검을 각각 실행한다. 남은 거래와 동시 작업을 차단한다.
- 기존 결제 제한시간과 오류 시 입실 중단을 유지한다. 현장 원인 확인을 위한 버전이며 원인 수정 완료를 뜻하지 않는다.

사용법과 한계: [현금 통신 점검](CASH_DIAGNOSTICS.md).

## 개발 PC 검증

- JavaScript/TypeScript 회귀 검사 288개 통과. 정상·거부·지연·무응답·전송 실패와 결제 저널/동시 작업 차단을 검사했다.
- Next.js 프로덕션 빌드와 타입 검사 통과.
- 운영 API와 실장비를 차단한 브라우저에서 점검 버튼 잠금, 지연/정상 결과 및 로그 표시를 확인했다.
- 로그 순환 보관, 실제 시리얼 로그 파싱, 민감정보 제외와 저장 실패 처리를 모의 검사했다.

릴리스 게시와 현장 설치/점검 결과는 별도로 확인한다. D동 외 장비에 업데이트를 요청하지 않는다.
