# 토스 프론트 LAN 연결 복구

1.3.6의 현금 취소·관리자 복구 패치는 토스 프론트 현장 연결 장애를 해결한 릴리스가 아니다.
같은 공유기에서 사용하는 연결은 `TOSS_FRONT_WS_URL=ws://프론트-IP:9000/kiosk`와
프론트 플러그인의 페어링 키가 필요하다. 설치형 키오스크는 등록 시 보관한 PC 설정을 사용한다.

## 1.3.7 변경

- IP만 입력하거나 기본 포트·경로가 빠진 ws 주소는 9000/kiosk로 보완한다. 명시한 다른 포트·경로는 보존한다.
- 연결 후 5초간 인증 응답이 없으면 연결을 종료하고 기존 지연 재연결을 실행한다.
- LAN 연결이 열린 것처럼 남은 상태는 WebSocket ping/pong으로 확인하고 다시 연결한다.
- 관리자 장비 상태에 실제 연결 주소, 네트워크/인증 상태, 마지막 오류를 표시한다.
- 승인 요청 전 인증에 실패하면 미전송으로 처리한다. 이미 보낸 승인 요청은 재전송하지 않고 기존 승인 복구 절차를 따른다.
- 승인 응답을 기다리는 동안 수동 재연결로 거래를 끊지 않는다.

## 현장 확인

같은 공유기여도 프론트 IP 변경, 게스트망 분리, 플러그인 미실행, 페어링 키 불일치가 있으면 연결되지 않는다.
관리자 장비 상태의 **토스 프론트**에서 표시한 주소와 오류를 프론트 화면의 실제 정보와 비교한다.
키오스크 설치파일과 토스 프론트 플러그인은 별도 배포물이며 이번 변경에 프론트 플러그인 업로드는 포함하지 않는다.

검증은 가짜 WebSocket 단말기의 인증 지연·거절·연결 단절·재연결과 기존 승인/취소/QR/승인 복구 통합 검사로 수행했다.
실제 1.3.6 현장 장애의 원인, 프론트 플러그인 상태, 실제 카드 승인 성공은 아직 검증하지 않았다.
