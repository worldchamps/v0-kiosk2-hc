# Kiosk 1.3.9 현금 결제 초기화 후 준비 확인

- D동 현장 로그에서 초기화 응답 직후 투입 중지가 무응답으로 끝나던 흐름을 보완했다.
- 결제 완료와 취소의 공용 초기화 함수가 3.5초 안정화 후 실제 대기 상태를 최대 3번 조회한다.
- 준비 확인 뒤에도 투입 중지 정상 응답이 있어야 예약 생성 또는 현금 반환으로 진행한다.
- 준비 미확인·장비 오류·정지 실패 시 현금 기록을 보존하고 기존 오류 처리로 중단한다.
- 초기화, 수취, 반환, 예약 생성을 자동 재시도하지 않는다. 기존 PC 설정과 거래 기록을 유지한다.

3.5초는 현장 관찰에 기반한 여유 시간이며 제조사 규격으로 확인된 값이 아니다.
개별 무현금 진단의 정상 결과만으로 실제 수납·입실 성공을 확정하지 않는다.
설치 후 결제 로그에서 `RST → 3.5초 이상 → GA 대기 → SC 정상`과 실제 입실 결과를 확인한다.

개발 PC 검증: JavaScript/TypeScript 테스트 296개와 Next.js 운영 빌드/타입 검사 통과.
현장 재현 모의 장비, 준비 상태 무응답/오류/계속 적재 중/늦은 준비, 결제/반환 순서 보호를 검사했다.
릴리스 게시와 D동 설치/현장 검증은 별도로 확인한다. [운영 절차](CASH_DIAGNOSTICS.md).
