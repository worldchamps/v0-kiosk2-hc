# Kiosk 1.3.10 Bixolon 프린터 SDK 포함

- 1.3.9 설치파일에 Bixolon SDK DLL이 빠져 인쇄할 수 없던 배포 결함을 수정한다.
- 64비트에는 `BXLPAPI_x64.dll`, 32비트에는 `BXLPAPI.dll`을 반드시 포함한다.
- 빌드 시 SDK 경로·파일명·비트수를 확인하고, 누락되면 설치파일 생성을 중단한다.
- 최종 패키지 검증은 내장 DLL의 비트수와 실제 함수 로딩까지 검사한다. COM 포트는 열지 않는다.
- 1.3.9의 현금 인식기 초기화 후 준비 확인을 포함하며, PC별 설정·거래 기록은 유지한다.

장비 설치 후 관리자 모드의 `프린터 테스트` → `테스트 인쇄`로 종이와 절단을 확인한다.
기존 화면의 인쇄 서버 연결·명령 전달은 물리 출력 성공을 뜻하지 않는다.
출력이 없으면 전원·용지·덮개·케이블과 실제 COM 포트 및 통신 속도를 확인한다.
설치파일의 DLL 로딩 검사는 현장 한글 영수증·정렬·용지 공급·절단 검증을 대신하지 않는다.

개발 PC 검증: JavaScript/TypeScript 회귀 검사 297개, Python 장비 계약 검사 17개와
Next.js 운영 빌드·타입 검사를 통과했다. SDK 누락·잘못된 파일명·비트수 불일치 시
빌드가 시작되지 않는 경우를 포함한다.
