# SNR-K750L 객실 카드키 운영 (1.3.25)

C105·C103의 고유번호만 발급한 카드로 문이 열린 현장 결과를 바탕으로, 등록 즉시 사용할 수 있는 객실별 등록과 체크인 자동 발급을 연결한다. 별도의 문 열림 확인 단계는 없다.

## 설정과 객실 등록

- 지원 PC는 C/D동 `property1`, A동 `property3` + `KIOSK_BUILDING=A`이다. 그 외 PC의 카드 발급 흐름은 실행하지 않는다.
- 관리자 진입: **Ctrl+Shift+Backspace** → 비밀번호 한 번 입력. 키보드와 Enter를 사용할 수 있다. 관리자 탭에서 추가 인증은 요구하지 않는다.
- **외부기기 등록**에서 실제 COM 포트, 장비 주소, **체크인 카드키 자동 발급 사용**을 저장하고 앱을 다시 실행한다. PC별 설정은 업데이트로 덮어쓰지 않는다. 기능이 꺼진 PC는 기존 영수증 안내로 운영된다.
- C/D동에서 확인한 설정은 COM3 / 9600bps / Device Number 08이다. 다른 PC의 포트·주소로 고정하지 않는다. 로컬 환경변수는 `CARD_DISPENSER_ENABLED`, `CARD_DISPENSER_PORT`, `CARD_DISPENSER_ADDRESS`이다. 통신은 9600/8/N/1, 주소는 00~15이다. 제조사 데모 프로그램은 종료한다.
- **객실 정보**에는 해당 PC의 담당 객실만 표시된다. 미등록 객실도 표시하며, 각 객실의 **원본 카드 등록**을 누르면 그 호수로 등록한다. 원본을 앞 투입구에 넣고 읽기가 끝나면 가져간다. 성공하면 즉시 ‘카드 등록됨 · 자동 발급 사용’으로 표시된다.
- **원본 카드 변경**은 해당 객실의 기존 등록을 확인한 뒤 교체한다. 실패 시 기존 등록은 유지한다. 기존 C103·C105 등록도 그대로 사용한다.
- 등록된 객실의 **카드 1장 발급**은 고유번호만 기록하는 빠른 방식이다. 카드함에는 제공된 Mifare 1K CUID 카드를 넣는다.

## 고객 체크인

1. 자동 발급을 켠 PC에서는 현장 결제 시작 전, 예약 체크인 요청 전에 원본 등록과 발급기 상태·재고를 확인한다. 미등록·카드 부족 시 결제/체크인을 시작하지 않는다.
2. 서버에서 체크인이 확정된 후 해당 예약·객실에 대한 서명된 발급 요청으로 카드 1장을 발급한다. 기존 예약과 현장 결제 예약에 동일하게 적용한다. 대기/실패 응답으로는 발급하지 않는다.
3. 카드 기록·검증 중에는 발급 안내, 배출 후에는 수령 안내를 표시한다. 수령 또는 회수 결과가 나온 뒤 기존 체크인 완료 화면과 영수증 출력으로 이어진다.
4. 카드 발급 실패는 결제 취소나 예약 재생성으로 처리하지 않는다. 결제와 체크인 완료 사실을 유지하고 카드 문제와 관리자 연락 안내를 표시한다.
5. 같은 예약의 중복 요청·서버 응답 재발급·앱 재시작은 로컬에 보관된 발급 결과를 재사용한다. 카드 이동 결과가 불명확하면 자동으로 다시 발급하지 않는다. 관리자는 **카드키** 탭의 **장치 상태** 또는 **회수함으로 회수**로 장비를 확인한 뒤 객실 정보에서 필요한 카드를 추가 발급한다.

## 기록 방식과 보관

- 원본은 읽기만 한다. 기존 등록 방식으로 UID, 블록 0, 일반 데이터와 인증 프로필을 저장한다.
- 일반 발급은 원본의 블록 0만 CUID 공카드에 기록하고, RF 고유번호와 블록 0을 다시 읽어 검증한다. 블록 1~63은 발급 시 읽거나 쓰지 않는다. 4바이트 UID를 지원하며 원본 UID·블록 0·BCC 일치도 확인한다.
- 데이터·UID·인증키 및 발급 이력은 해당 Windows PC의 Electron `safeStorage`로 암호화하여 `card-keys`에 원자적으로 저장한다. 화면에는 등록 호수·일시와 작업 결과만 전달한다. 원본 데이터는 브라우저·로그·클라우드로 보내지 않는다. 다른 PC로 파일 복사하는 방식의 이전은 지원하지 않는다.
- 현장 결제의 미완료 처리 기록은 카드 발급 결과를 받을 때까지 유지한다. 재실행 시 같은 예약 처리 결과를 확인하면 저장된 발급 이력을 이용한다.

## 장비 복구

- 앞에 나온 카드를 60초 동안 가져가지 않으면 회수함으로 회수한다. 원본도 미수령 시 직원이 회수함에서 찾아야 한다.
- 이송·기록 결과가 미확정이면 추가 발급·화면 복귀·업데이트 설치를 막는다. 장치 상태 조회만 실패한 경우에는 새로운 카드 이동으로 취급하지 않는다.
- **장치 상태**는 통신을 재연결하여 상태만 조회한다. **회수함으로 회수**는 장비 안의 카드를 회수한다. 빈 장비에서만 초기화한다. **카드 반납**은 카드함으로 회수하며 체크아웃을 처리하지 않는다.
- 원본 읽기에 실패하더라도 반환 후 최초 오류를 표시한다. 반환 성공을 등록 성공으로 취급하지 않는다. 오류에는 실패 명령·블록·장비 코드 및 통신 정보만 표시한다.

## 검증

자동 검사는 가상 RS232 통신, 원본 읽기 전용, UID 기록·검증, 미수령 회수, 암호화 저장, PC별 범위, 관리자 인증 재사용, 객실 카드 UI, 체크인 완료 서명, 중복·재시작 발급 방지, 결제 전 점검 및 발급 실패 후 결제 유지 흐름을 확인한다. 기존 문 열림 현장 결과는 유지하며, 새 자동 체크인 연결의 실제 카드 배출은 설치 장비에서 확인할 수 있다.
