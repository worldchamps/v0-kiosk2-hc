# PMS 객실 카드키 배출 (1.3.27)

- PMS 객실 상세의 **객실키 배출**로 카드 1장과 객실 안내문을 요청한다.
- A동은 확인된 `property3-kiosk-01`, C·D동은 `property1-kiosk-01`에서만 처리한다. B동·카리브·캠프의 기존 처리 경로는 바꾸지 않는다.
- 원본 카드가 등록되어 있고 카드 발급기 설정이 켜져 있어야 한다. 고객 결제·체크인 중에는 요청을 기다렸다가 첫 화면에서 처리한다. 요청은 10분 후 만료된다.
- C동 체크인/관리자/원격 안내문은 비밀번호와 숫자 입력 설명을 제거하고 카드키 이용법을 출력한다. A·D동의 비밀번호 출력은 기존대로다.
- PMS는 `kiosk_key_jobs/{property}/{id}`에 서명된 요청을 저장한다. 기존 객실관리 PC 명령 대기열에 카드키 배출을 중복 전송하지 않는다. 입실·예약·결제 상태는 이 버튼으로 바뀌지 않는다.
- PMS의 기존 서버 서비스 계정 키로 도메인이 구분된 요청에 서명한다. 키오스크와 PMS의 `pms-card-public-key.json`/`kiosk-key-public-key.json`에는 공개 검증키만 포함한다. 서비스 계정 키를 교체하면 새 공개키를 검증하여 양쪽 코드를 함께 갱신해야 한다. 개인키나 카드 원본 데이터는 대기열로 보내지 않는다.
- 서명·객실·숙소·장비 ID·유효기간을 로컬 서버와 Electron에서 검사한다. 동일 요청의 카드 결과는 기존 암호화 저장소에 남겨 재수신·재시작으로 두 장을 발급하지 않는다. 인쇄 시작을 기록한 후 출력하므로 결과가 불확실한 인쇄를 자동 반복하지 않는다.
- 실제 카드 수령은 발급기 결과로 확인한다. 인쇄 결과는 명령 전달 결과이며, 용지 공급·절단은 현장에서 확인한다.
