# PMS 키오스크 화면 조회

PMS 객실관리의 **키오스크 화면 보기**에서 등록 장비를 선택해 시작한다.
Electron이 키오스크 창이 있는 모니터의 실제 바탕화면을 JPEG로 캡처한다.
가려진 창·오류 창도 그대로 보이며 화면 조회는 결제나 키 배출을 실행하지 않는다.

- 설치 앱과 PMS 양쪽에 해당 기능이 반영되어야 한다. 장비의 기존 `KIOSK_DEVICE_ID`, 숙소·동 설정과 Firebase 서버 자격증명을 사용한다.
- 조회 요청이 없으면 화면을 캡처하지 않고 15초 간격으로 연결 정보만 보고한다. 조회 중에는 약 5초 간격이며 정상 연결에서도 최초 캡처까지 수십 초 걸릴 수 있다.
- PMS 로그인과 동일 출처 요청을 확인한 뒤 5분짜리 조회 요청을 저장한다. 중지·숙소 변경·화면 이탈은 해당 요청만 종료한다.
- Electron 보고는 HMAC 서명, 장비·숙소·동 일치, 시각, 이미지 형식·크기를 확인한다. Firebase의 `kiosk_screens` 경로는 외부 공개 읽기를 허용하면 안 된다.
- 이미지는 최신 1장만 저장한다. 요청 종료 후 다음 보고 때 삭제하며 장비가 끊겼을 때 남은 이미지는 5분 후 PMS 응답에서 제외한다. 30초 이상 된 화면은 오래된 캡처로 표시한다.
- 앱 소스 빌드와 가상 화면 테스트는 실제 모니터 캡처·현장 네트워크 확인을 대체하지 않는다.
