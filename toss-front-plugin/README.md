# 더 비치스테이 토스 프론트 플러그인

토스플레이스 공식 `front-plugin-websocket-js` 템플릿과 Front SDK v1을 기반으로 한
키오스크 결제 플러그인입니다.

개발자센터 ACL에는 공식 SDK와 템플릿 스타일을 불러오기 위해 다음 주소를 등록하세요.

- `https://cdn.tossplace.com`
- `https://static.toss.im`

## 테스트

1. 토스플레이스 개발자센터에서 토스 프론트 플러그인을 생성합니다.
2. 이 폴더의 파일을 ZIP 루트에 오도록 압축해 개발 배포에 업로드합니다.
3. 테스트 가맹점과 테스트 프론트 단말기에 플러그인을 활성화합니다.
4. 프론트의 플러그인 설정 화면에서 키오스크의 `TOSS_FRONT_PAIRING_KEY`와 같은
   16자 이상의 페어링 키를 저장합니다.
5. 프론트가 출력한 IP를 이용해 키오스크의 `TOSS_FRONT_WS_URL`을
   `ws://<프론트-IP>:9000/kiosk`로 설정합니다.

카드 테스트는 실제 승인이 발생할 수 있습니다. 승인 결과의 승인번호와 승인시각을
보관하고 테스트 직후 승인 취소를 진행하세요.

## 예약 QR 확인

키오스크의 예약 확인 화면에서 `토스 프론트로 QR 확인`을 누르면 프론트의 공식
`renderQRScanPage` 템플릿이 카메라를 실행합니다. 지원하는 QR 값은 다음 형식입니다.

```text
AGAIN:RESERVATION:R20260728-8K4M2
```

마지막 값은 Google Sheets `Reservations` 시트의 예약번호와 정확히 일치해야 합니다.
스캔에 성공하면 키오스크가 예약번호로 예약을 조회하고 예약 상세 화면을 바로 표시합니다.
